# 大运顺逆规则

`LUCK_DIRECTION_YEAR_STEM_SEX_V1` 采用：阳年男、阴年女顺行；阴年男、阳年女逆行。男女字段只服务于该传统二分规则，不参与四柱计算。

## 典据边界

2026-08-13 对照《古今图书集成》艺术典卷六百二十四所收《三命通会》〈消息赋下〉影像。该页明确出现“阳男阴女运顺行”及阴阳男女依逆顺行运的注释语境。影像页在维基文库标为“尚未校对”，因此玄象把它记为后世定式（`LATER_FORMULATION`）与传统归属（`TRADITIONAL`），不宣称这是该规则的最早来源，也不宣称所有流派唯一采用此法。

## 玄象形式化

玄象以年柱天干阴阳和输入的传统男女分类返回 `FORWARD` 或 `BACKWARD`。枚举、输入校验、缺少 sex 时的错误处理属于软件形式化，不属于原典文字。
