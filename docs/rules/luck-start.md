# 起运折算规则

`LUCK_START_JIE_3DAYS_V1` 顺行取出生后的下一“节”，逆行取出生前的上一“节”，复用经过验证的 Solar Term Service；持续时间按三日折一年关系转换为 `AgeDuration`。

## 典据边界

《古今图书集成》艺术典卷六百二十四所收《三命通会》〈消息赋下〉影像在“依逆顺行运折除”语境中出现“折除三岁为年”的转录文字，并说明以节气日数定行运岁数。该数字页未校对，措辞亦不足以逐项规定现代软件的余小时、余分钟和取整方法，因此证据状态保持 `TRADITIONAL`，不包装为所有工程细节的直接定义。

## 玄象形式化

玄象用标准化 UTC instant 计算到目标节的连续分钟，以 4320 分钟折一年，再分解成年、月、日、时。结果精度保持 `TRADITIONAL_APPROXIMATION`。`luck-02` 与 `luck-05` 相对交叉 Provider 的一日差异来自余小时的表示/取整路径，已分类为 Provider difference；没有证据表明需要新增传统 rounding policy。
