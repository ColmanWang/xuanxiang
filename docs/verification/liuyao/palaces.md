# 八宫验证

## 已验证范围

- 乾、兑、离、震、巽、坎、艮、坤八宫。
- 每宫本宫、一至五世、游魂、归魂八个位置，共 64 项。
- 每一卦只归属一个宫位；宫位的五行可稳定供六亲计算使用。

## 独立性

生产代码依据翻爻序列计算宫位；`fixtures/liuyao/palaces.ts` 保存静态 8 × 8 表，不导入生产 mask、宫序或 helper。Phase 8.5 增加 8 个游魂与 8 个归魂专项回归，防止归魂掩码问题再次出现。

机器可读 `LIUYAO_HEXAGRAM_MANIFEST` 另记录 64 卦的卦序、上下卦、宫位、宫序、世爻与应爻，作为升级回归清单。Manifest 是回归产物，不替代独立 Golden。

## 来源与证据边界

- 公开转录：[《事林广记》续集卷十一](https://zh.wikisource.org/zh/事林廣記/續集/卷11)，卜史类“推八卦所生数游魂归魂诀”。
- 数据库定位：`passage-shilin-eight-palaces` / `citation-liuyao-palaces`。
- `EvidenceStatus = TRADITIONAL`：该段支持后世八宫卦序定式，不表示《周易》经文直接给出八宫表。
- 数字转录已核对页面，仍待版本影像逐字校订。

## 已知历史边界
