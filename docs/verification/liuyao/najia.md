# 纳甲验证

## 已验证范围

- 八纯卦六爻的天干、地支，共 48 个逐爻位置。
- 下卦使用内卦纳甲、上卦使用外卦纳甲的装配方向。
- 64 卦共 384 爻均可得到合法的完整纳甲结果。
- 内部爻序始终为 `index 0 = 初爻`、`index 5 = 上爻`。

## 独立性边界

生产实现位于 `lib/liuyao/najia.ts`；静态 Golden 位于 `fixtures/liuyao/najia.ts`，测试不导入生产纳甲常量。Phase 8.5 又将八纯卦 48 项与《项氏家说》卷二公开数字转录中的逐爻表核对，并建立 Passage 级 Citation。

这形成了“生产常量—测试静态表—传统文献转录”三层核对，但仍不是现代权威校本或外部完整盘例验证。因此当前验证等级保持 `CROSS_CHECKED`，不提升为 Tier A。

## 来源与证据边界

- 公开转录：[《项氏家说（四库全书本）》卷二](https://zh.wikisource.org/wiki/項氏家説_(四庫全書本)/卷02)。
- 数据库定位：`passage-xiangshi-najia` / `citation-liuyao-najia`。
- `EvidenceStatus = TRADITIONAL`：该文献支持南宋时期对八纯卦逐爻纳干支的明确记载，但不能证明全部规则由《周易》经文直接规定，也不解决纳甲最早形成时间。
- Witness 标记为公共领域数字转录摘录、`BASIC`，仍待版本影像逐字校订。

## 未验证

- 纳甲传统与京房本人著述之间的精确传承链。
- 不同文献系统中的异表、异文及其版本学关系。
- 可满足 Tier A 标准的外部完整六爻盘例。
