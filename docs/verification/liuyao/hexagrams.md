# 六十四卦验证

## 验证对象

- 八卦三爻结构。
- 8 × 8 六十四卦组合。
- 卦序编号与上下卦结构分离。
- 4096 种 6/7/8/9 爻值组合的本卦、动爻、变卦合法性。

## 当前方式

- `lib/liuyao/hexagrams.ts` 作为生产映射。
- `lib/liuyao/liuyao.test.ts` 验证 64 卦唯一、编号完整、4096 动变不崩溃且变卦合法。
- 20 个上下卦不对称样例单独锁定 `lowerTrigram` / `upperTrigram` 方向，避免纯卦掩盖上下卦转置错误。
- 8 宫的游魂、归魂共 16 项作专项 regression，不只依赖 64 卦总表。
- 4096 组合额外验证：动爻数为 0–6；无动爻时变卦为 `null`；六爻全动时全部阴阳反转。
- `LIUYAO_HEXAGRAM_MANIFEST` 将 64 卦的卦序、名称、上下卦、宫位、宫序、世应固化为机器可读升级清单。

## 限制

- 本阶段未创建 64 个知识条目。
- 卦辞与爻辞不自动进入六爻计算结果。
- Manifest 用于检测输出漂移，不是独立历史证据；八宫、世应与纳甲仍由各自 Golden 和 Rule Provenance 承担验证。
