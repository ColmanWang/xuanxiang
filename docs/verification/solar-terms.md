# 节气验证

生产 provider 为 `lunar-typescript 1.8.6`。仓库固定 60 条节气 fixture，覆盖 1901、1920、1950、1980、2000、2024、2026、2050、2083、2100。2024 与 2026 以香港天文台公开分钟表为权威 fixture；其余年份以 Y. T. Liu 基于 JPL DE441 的公开计算资料作交叉确认。

资料精确到分钟，容差分别为 60 秒和 90 秒。`pnpm calendar:verify-terms` 输出每条 expected、actual、delta，以及最大误差、中位误差和失败数。节月边界另在 provider 实际秒级时刻执行 T−60s、T−1s、T、T+1s、T+60s 翻柱测试。

未验证：秒级“绝对真值”。公开历算因 ΔT、取整和算法版本可能有秒至分钟差异，因此结果页在 ±5 分钟显示边界提醒。
